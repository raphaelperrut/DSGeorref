# Política de segurança

Durante a incubação privada, vulnerabilidades, secrets ou dados pessoais devem ser comunicados diretamente ao mantenedor por canal privado. O canal público definitivo será definido antes da abertura do repositório.

Escopo mínimo de revisão: autenticação, autorização, raízes de workspace, path traversal, symlink escape, arquivos hostis, decompression bombs, parsers GIS/GDAL, SSRF, command injection, secrets, dependências, modelos/checkpoints, logs, artefatos, downloads e operações destrutivas.

Não existe API implementada nesta fundação. Qualquer futuro serviço exposto em rede permanece `NO_GO` até os gates de acesso e segurança.
