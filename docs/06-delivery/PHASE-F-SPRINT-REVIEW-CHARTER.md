# Fase F — Sprint Review Charter

## Objetivo

Revisar cada sprint e cada issue nas dimensões dependências, arquivos, API, banco, frontend, geo, IA, testes, artefatos, critérios e review, registrando `NOT_APPLICABLE` em vez de inventar escopo.

## Gate

Nenhuma sprint ou issue é `Ready` se uma dimensão aplicável estiver sem authority, contrato, write scope, teste, evidência ou reviewer. A aprovação da revisão não concede autorização para implementação.
