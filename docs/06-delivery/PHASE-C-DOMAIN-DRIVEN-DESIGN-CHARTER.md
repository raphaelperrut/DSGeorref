# Charter — Fase C Domain Driven Design

## Objetivo

Separar o roadmap e a arquitetura em bounded contexts, distinguindo capacidades de negócio de UI, IA, backend, Geo, storage e jobs.

## Escopo

- identificar subdomínios e contextos;
- definir linguagem ubíqua, aggregates, eventos e ownership;
- criar context map e padrões de integração;
- reconciliar sprints, épicos, issues, requisitos, ADRs, contratos, módulos e TaskEnvelopes;
- bloquear modelo global, dependências circulares e acesso cross-context.
