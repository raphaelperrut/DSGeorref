# Integração técnica

Integre primeiro os contratos compartilhados e regenere clientes e bindings afetados. Coordene domínio, migrations e adapters pela interface versionada. Rode testes de compatibilidade, integração e E2E pertinentes em ambiente limpo.

Quando um consumidor precisa de apenas parte de uma entrega, aponte na issue para o incremento integrado e seu teste. Use as dependências do GitHub para os bloqueios técnicos. Consulte a [governança](../../GOVERNANCE.md) para revisão e merge.
