# Native stack and planning governance foundation

This slice materializes one candidate policy and a fail-closed validator for
the ten requirements owned by `STORY-0694`. The policy records only invariants
already established by the cited requirements, ADRs, the frozen engineering
foundation conformance profile, and `AP-006`. It does not implement the
geospatial runtime, select quantitative matching parameters, mutate GitHub, or
publish OCI, ABI, COG, benchmark, security, or production-readiness claims.

`policy_validation.load_policy` rejects missing, extra, mistyped, or changed
controls without a permissive fallback. Native controls preserve RootSIFT,
FLANN with a controlled exact BF oracle, pinned and encapsulated OpenCV/
USAC_MAGSAC, independent COG validation, coherent OCI/ABI promotion, and
allowlisted I/O with work-unit-local handles. Planning controls keep roadmap
horizons/outcomes/gates, layered milestones, auditable sequencing, and critical
dependency/risk-buffer classification explicit.

## Boundaries and handoff

- Contract impact: none; frozen public contracts, profiles, and ADRs are unchanged.
- Persistence, HTTP, broker, migration, live GitHub mutation, and native runtime
  materialization: not applicable to this local foundation slice.
- Risk: this remains a candidate until independent QA and Reviewer validate the
  exact commit; later stories own runtime and repository integration.
- Rollback: revert the candidate commit. No data migration or destructive
  rollback is required.
