# Domain-Driven Design — início

A Fase C separa capacidades de negócio de componentes técnicos. `Web UI`, `HTTP API`, `PostgreSQL`, `Filesystem`, `RabbitMQ`, workers e runners são canais, adapters ou infraestrutura; não são bounded contexts.
