# Linguagem ubíqua

Termos são locais ao bounded context. O mesmo nome não pode representar conceitos incompatíveis.

| Contexto | Termos reservados |
|---|---|
| `BC-001` | `decisão arquitetural`, `baseline normativa`, `história implementável`, `TaskEnvelope`, `evidência de sprint` |
| `BC-002` | `conta`, `sessão`, `token pessoal`, `membership`, `autorização` |
| `BC-003` | `projeto`, `workspace root`, `entrada do workspace`, `asset`, `snapshot de seleção` |
| `BC-004` | `ProcessingPlan`, `estágio`, `capability`, `PlanVariant`, `política de processamento` |
| `BC-005` | `provider`, `candidate`, `busca espaciotemporal`, `aquisição`, `grafo de referências` |
| `BC-006` | `attempt`, `correspondência`, `GCP automático`, `homografia`, `grade de saída` |
| `BC-007` | `SGV`, `hard gate`, `QualityProfile`, `veredito`, `deformação` |
| `BC-008` | `mosaico relativo`, `componente`, `âncora`, `otimização global`, `promoção` |
| `BC-009` | `ModelPack`, `ModelRunner`, `capability de IA`, `recuperação neural`, `promotion record` |
| `BC-010` | `job`, `work unit`, `attempt de execução`, `checkpoint`, `lease`, `scheduler policy` |
| `BC-011` | `caso de revisão`, `fila de revisão`, `CorrectionSet`, `GCP manual`, `decisão de revisão` |
| `BC-012` | `resultado vigente`, `snapshot`, `diagnóstico`, `comparação`, `export` |
| `BC-013` | `ArtifactSet`, `artifact object`, `manifest`, `lineage`, `BackupSet`, `RetentionPolicy`, `tombstone` |
| `BC-014` | `audit record`, `sinal operacional`, `readiness`, `drain`, `support bundle`, `restore drill` |
| `BC-015` | `installation plan`, `upgrade plan`, `release candidate`, `milestone`, `attestation`, `rights manifest` |
| `BC-016` | `jornada guiada`, `filtro salvo`, `preferência`, `ajuda contextual`, `view state` |
